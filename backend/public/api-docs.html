CRM RBAC Permission Management API v1.0.0

Complete RESTful API for Role-Based Access Control with hierarchical roles, time-based assignments, and comprehensive audit logging

🎯 Features

  • Role and permission management
  • Hierarchical role inheritance
  • Time-based role assignments
  • Scope-based permissions
  • Comprehensive audit logging

🔐 Authentication

All endpoints (except login/refresh) require a JWT Bearer token in the Authorization header:

Authorization: Bearer <your-token>

🚀 Getting Started

1. Authenticate via /auth/login
2. Use the returned token for API calls
3. Refresh token before expiry
4. Check specific endpoint docs below
